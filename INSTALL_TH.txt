JIN Cashbook Mobile V1 - วิธีติดตั้งแบบง่าย

สำคัญ:
- หลังติดตั้ง/โหลดเว็บแอปเข้ามือถือเรียบร้อยแล้ว สามารถใช้งานโดยไม่ต้องต่ออินเทอร์เน็ตได้
- ข้อมูลหลักเก็บในเครื่องด้วย IndexedDB
- ต้องต่ออินเทอร์เน็ตเฉพาะตอน "ติดตั้งครั้งแรก/ดาวน์โหลดตัวเว็บ" หากใช้ระบบติดตั้งแบบ PWA ผ่าน HTTPS
- ก่อนล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ให้ Backup JSON เสมอ

Android / Samsung:
1. เปิด URL ของ JIN Cashbook Mobile ด้วย Chrome
2. เลือก "ติดตั้งแอป" หรือ "เพิ่มไปยังหน้าจอหลัก"
3. เปิดจากไอคอน JIN Cashbook
4. หลังจากติดตั้งและโหลดไฟล์ครบแล้ว สามารถใช้งานออฟไลน์ได้

iPhone / iPad:
1. เปิด URL ด้วย Safari
2. กด Share
3. เลือก "Add to Home Screen / เพิ่มไปยังหน้าจอโฮม"
4. เปิดจากไอคอน JIN Cashbook
5. หลังจากโหลดแอปครบแล้ว สามารถใช้งานออฟไลน์ได้

Backup:
- กด "สำรองข้อมูล JSON"
- บันทึกไฟล์ไว้ใน iCloud Drive / Google Drive / OneDrive / PC / USB
- เมื่อต้องการย้ายเครื่อง ให้เปิด JIN Cashbook บนเครื่องใหม่แล้วกด Restore

การใช้งานกับ V3 Windows:
- Mobile ใช้โครงสร้างข้อมูล JIN_CASHBOOK version 1
- แต่การนำ Backup เข้า V3 Windows จะต้องให้ V3 รองรับ Import/Restore schema นี้ก่อน
- ไม่แก้ไข V3 เดิมในแพ็กเกจนี้
